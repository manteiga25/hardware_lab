      Como calculamos o custo × performance

      A base de dados guarda a posição de cada processador numa lista de desempenho e o preço registado. A partir daí calculamos estes valores.

      Índice de desempenho

      100 × (N + 1 − posição) ÷ N

      Converte a posição no ranking numa escala de 0 a 100, em que N é a última posição da lista. O primeiro da lista tem 100. Um índice de 75 quer dizer que é mais rápido do que cerca de 75% dos processadores registados.

      Custo por ponto de índice

      preço ÷ índice

      Quanto pagas por cada ponto de desempenho. É a métrica principal de custo × performance: quanto mais baixa, mais desempenho recebes por cada dólar.

      Custo dos pontos extra

      diferença de preço ÷ diferença de índice

      Quando o processador mais rápido também é o mais caro, mostra quanto pagas por cada ponto a mais. Se for bastante acima do custo por ponto do mais barato, o desempenho extra está caro.

      Limites dos dados

      O índice diz qual é mais rápido, mas não quanto mais rápido, porque vem de uma posição e não de um teste. No topo da lista, um ponto pode esconder uma diferença grande. Preço, turbo ou TDP a zero na base de dados significam valor desconhecido: aparecem como “sem dados” e ficam fora das contas de custo.

      As especificações vêm da base de dados do projeto e podem ter erros. Confirma no site do fabricante antes de comprar.
