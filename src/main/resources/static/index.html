Como calculamos o custo × performance

A base de dados dá a cada produto uma medida de desempenho e guarda o preço registado. A partir daí calculamos estes valores, da mesma forma para processadores e placas gráficas.

Índice de desempenho

Processadores: 100 × (N + 1 − posição) ÷ N

Placas gráficas: pontuação ÷ 10

Os processadores têm uma posição num ranking, em que N é a última posição da lista. As placas gráficas têm uma pontuação de 0 a 1000. As duas passam para a mesma escala de 0 a 100: um índice de 75 quer dizer mais rápido do que cerca de 75% dos produtos do mesmo tipo.

Custo por ponto de índice

preço ÷ índice

Quanto pagas por cada ponto de desempenho. É a métrica principal de custo × performance: quanto mais baixa, mais desempenho recebes por cada dólar. Só compara produtos do mesmo tipo.

Custo dos pontos extra

diferença de preço ÷ diferença de índice

Quando o mais rápido também é o mais caro, mostra quanto pagas por cada ponto a mais. Se for bastante acima do custo por ponto do mais barato, o desempenho extra está caro.

Limites dos dados

O índice diz qual é mais rápido, mas não exatamente quanto, porque vem de uma posição ou pontuação e não de um teste feito aqui. Nas placas gráficas, o preço é o de lançamento e as mais antigas não têm pontuação. Valores a zero ou em falta aparecem como “sem dados” e ficam fora das contas de custo.

As especificações vêm da base de dados do projeto e podem ter erros. Confirma no site do fabricante antes de comprar.
